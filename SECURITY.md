## 🇬🇧 English

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/chiaraberti13/Rfnm-sdrpp-setup/security/advisories/new). Include the affected commit, operating system, hardware, reproducible steps and sanitized logs. Do not publish credentials, device identifiers or unpatched vulnerabilities.

Review scripts before running them with elevated privileges. Test only systems and hardware you own or are authorized to administer.

## 🇮🇹 Italiano

Segnala privatamente le vulnerabilità sospette tramite [GitHub Security Advisories](https://github.com/chiaraberti13/Rfnm-sdrpp-setup/security/advisories/new). Indica commit, sistema operativo, hardware, passaggi riproducibili e log privati di dati sensibili. Non pubblicare credenziali, identificativi dei dispositivi o vulnerabilità non corrette.

Verifica gli script prima di eseguirli con privilegi elevati. Esegui test esclusivamente su sistemi e hardware di tua proprietà o che sei autorizzata ad amministrare.
